# VoiceImitator

Озвучивает введённый текст нейроголосом и выводит звук в виртуальный кабель,
который Discord видит как микрофон, — друзья в голосовом канале слышат озвучку.
Синтез работает локально, без интернета (модель Silero скачивается один раз).

## Что умеет

- Пять русских голосов и пресеты («Диктор дорам», «Бурундук», «Великан»).
- Скорость и тон — независимыми ползунками, плюс громкость.
- Вывод в виртуальный кабель для Discord, одновременно — себе в наушники.
- Пропуск живого микрофона в тот же кабель: друзья слышат и озвучку, и ваш голос.
- История фраз: клик повторяет фразу.
- Кабель VB-CABLE не найден — программа предлагает установить его из встроенного
  оригинального установщика.
- Оформление **Night Glass** из ZapretLauncher: фото-фон, матовое стекло, акцент
  с палитрой, настройки фона и стекла.

## Запуск из исходников

Нужен Python 3.11+ на Windows.

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
run_app.bat
```

`run_app.bat` запускает `.venv\Scripts\python -m app`. Видеокарта не нужна.

## Звук в Discord

1. Если виртуального кабеля нет, во вкладке «Настройки» будет кнопка
   **«Установить кабель»**: подтвердите запрос прав Windows и в окне VB-CABLE
   нажмите **Install Driver** (иногда после этого нужна перезагрузка).
2. Программа сама выберет **CABLE Input** в поле «Микрофон для Discord».
3. В Discord → Настройки → Голос и видео → Устройство ввода → **CABLE Output**.

Пишите текст и жмите **Ctrl+Enter**.

## Оформление

Вкладка «Оформление» повторяет настройки ZapretLauncher:

- **Цвет-акцент** — квадрат насыщенности и яркости, полоса оттенков, восемь готовых
  цветов и поле `#RRGGBB`. Акцентом красится только то, что «работает»: вкладка,
  ползунки, включённые переключатели.
- **Фон** — встроенная картинка, своя картинка или звёздное небо.
- **Яркость фона**, **размытие фона** и **размытие стекла** — в процентах, как в лаунчере
  (по умолчанию 50%, 0% и 60%).

Как устроено: `app/theme.py` — токены дизайн-системы, `app/backdrop.py` — фон,
`app/glass.py` — стекло (под каждой панелью вклеивается размытый, затемнённый и
высветленный вуалью фон с обводкой 1px; подписи рисуются прямо на стекле, а под
каждый контрол подкладывается его кусок фона, чтобы скруглённые углы ложились на
настоящее стекло), `app/picker.py` — палитра акцента.

## Сборка в .exe

```
.venv\Scripts\python -m pip install pyinstaller
.venv\Scripts\python tools\build_exe.py
```

Получится один файл `dist\VoiceImitator.exe` (~175 МБ: внутри PyTorch). Голосовая
модель в него не входит — скачивается при первом запуске в `%APPDATA%\VoiceImitator`.
